# 编曲质量指标

> AI 生成编曲数据时参考。分两层：硬指标（必须遵守）+ 参考方向（默认起点，可打破）。
> 参数范围按 `fw_desc_new.txt` 实测值校准。

---

## 一、硬指标（违反会出问题）

### 协议与硬件约束

| 项目 | 约束 | 说明 |
|---|---|---|
| 轨道数 | 固定 4 轨 | 0=旋律、1=和弦、2=贝斯、3=鼓（可自行调整） |
| 步数 | 每轨 ≤ 64 步 | `nstep=64` |
| 步索引 | 0-63 | 超出会被忽略 |
| 音符数 | 每步 ≤ 4 | `n=0-4`，超出截断 |
| 音高 | 0-127 | 超出会被拒绝 |
| 力度 | 0-127 | 超出截断 |
| time 值 | 0=NOTE / 1=TIE / 2=REST | 其他值无效 |
| flags | 1=accent / 2=slide | 位掩码 |
| chance | 0-100 | 概率百分比 |
| DIV 枚举 | 0=1/4 1=1/8 2=1/16 3=1/32 4=8T 5=16T 6=1/2 7=1/1 | 只有这 8 个 |
| 鼓位掩码 | 8 位 lane | bit0=KICK bit1=SNARE bit2=CLAP bit3=HATCL bit4=HATOP bit5=TOM bit6=RIM bit7=BELL |
| 槽位 | A/B/C/D（0-3） | PROJECT 槽 |
| SONG 行数 | 长度 = 2 + 2×行数 | 必须精确 |

### 音乐硬指标

| 类别 | 约束 |
|---|---|
| **音区** | 贝斯 C1-C3（24-48）、和弦 C3-C5（48-72）、旋律 C4-C6（60-84） |
| **低频分离** | 底鼓（50-80Hz）与贝斯（80-250Hz）错开频率 |
| **和弦功能** | 每个和弦必须能解释功能（T/S/D 或 borrowed） |
| **TIE 语义** | `time=1` 必须**前有 NOTE 起始步**，整段全 TIE = 静音 |

### ⚠️ 带符号参数的处理

以下参数范围**跨零**，v14 编码本身支持负值，但生成编曲数据时要明确：

| 参数 | 范围 | 0 的含义 |
|---|---|---|
| FLT（轨道 id=5） | -64~63 | 0 = 无滤波（中性） |
| TUNE（全局 id=3） | -50~50 | 0 = 标准调音（440Hz） |
| PAN（轨道 id=39） | -64~63 | 0 = 居中 |

**v14 编码验证**：`v14enc(-64) = -64 + 8192 = 8128 = [0, 63]`，负值可正常编码。

**生成时的检查**：
- `FLT` 不要写 0-127，范围是 **-64~63**
- `TUNE` 不要写 0-127，范围是 **-50~50**
- `PAN` 不要写 0-127，范围是 **-64~63**

**默认值建议**：
- FLT = 0（不滤波）
- TUNE = 0（标准调音）
- PAN = 0（居中）

### 参数检查清单（生成编曲数据时）

- ✅ SWG 值范围 **0-100**（不要写 101-127）
- ✅ LEN 值范围 **1-64**（不要写 0 或 65+）
- ✅ GATE 值范围 **1-127**（0 会导致音符无声）
- ✅ FLT 值范围 **-64~63**（不要写 0-127）
- ✅ TUNE 值范围 **-50~50**（不要写 0-127）
- ✅ PAN 值范围 **-64~63**（不要写 0-127）
- ✅ RATE 值范围 **0-5**（枚举）
- ✅ CLK 值范围 **0-2**（枚举）

## 二、参考方向（默认起点，可打破）

### 结构

| 参考方向 | 说明 |
|---|---|
| 单段循环 | ≤ 32 步（2 小节） |
| 主副部 | 64 步（4 小节 × 2 段） |
| 超长结构 | 双槽 SONG 链（如 64 + 32 步） |
| 段落长度 | 2 的幂 |

**打破的场景**：前卫摇滚奇数拍、后摇渐进、自由爵士。

### 律动

| 参考方向 | 说明 |
|---|---|
| BPM 72 | 舒缓 |
| BPM 88 | 轻快 |
| BPM 100 | 行进 |
| SWG 0-30 | 轻微摇摆 |
| SWG 40-60 | 爵士/布鲁斯摇摆 |

**注意**：SWG 上限是 **100**，不是 127。

### 配器

| 轨 | 参考角色 | 音区 |
|---|---|---|
| 0 | 旋律 | C4-C6 |
| 1 | 和弦 | C3-C5 |
| 2 | 贝斯 | C1-C3 |
| 3 | 鼓 | DRUM 引擎 8 件套 |

### 织体

| 参考方向 | 说明 |
|---|---|
| 旋律级进为主 | 二度音程约 60% |
| 一个高潮点 | 位于段落 2/3 处 |
| 分解和弦有走向 | 音区拱形、voice leading、提前导向 |
| 贝斯根音+五音 | 简单稳定 |

## 三、创作原则

1. **用户意图优先**。用户说"来点不协和的"就给不协和。
2. **允许实验**。打破参考方向时只要硬指标不违反，就是合格创作。
3. **惊喜优先于规范**。某个"不规范"的处理听起来更好，就选它。
